<details><summary><b>View Test Case Data</b></summary>

- **Input:** How do ML systems and LLM apps differ in determinism, dynamic cost, and input-output tracking?
- **Actual Output:** Determinism
- ML systems: outputs and evaluation are straightforward and mathematically calculable (accuracy, precision, recall, F1). Predictions are immediate and you can directly compare ŷ and y.
- LLM apps: outputs are not so straightforward; metrics are complex and application-specific, so behavior and evaluation are less deterministic.

Dynamic cost
- ML systems: compute/cost is relatively predictable for a given input size (you spend roughly the same units for the same amount of data).
- LLM apps: compute and cost change dynamically with the input, the output, and retrieved context — usage and compute vary as the conversation or retrieval changes.

Input–output tracking
- ML systems: you generally do not need to track the entire input-to-output journey for a simple prediction because there is no multi-step workflow; the model takes input and immediately gives output.
- LLM apps: there is a workflow that can vary in length and complexity, so tracking the steps and the flow is necessary and changes your LLM-ops requirements.
- **Expected Output:** ML systems are generally deterministic: the same input row gives the same output every time, with fixed compute/cost for that input size.  

LLM apps are probabilistic and dynamic: the same input can produce different outputs, and both cost and compute vary because input length, output length, and retrieved context all change.  

Also, ML prediction usually has a simple input-to-output flow, while LLM apps often require tracking the full journey from input through retrieval, prompting, and output.

</details>
